# 01. 서비스 기획서 — AIHF Web

| 항목 | 내용 |
| --- | --- |
| 문서 버전 | v1.0 (2026-11-17) |
| 프로젝트 | AIHF Web — `ai-hedge-fund` 엔진을 브라우저에서 쓰는 웹앱 |
| 기반 오픈소스 | [virattt/ai-hedge-fund](https://github.com/virattt/ai-hedge-fund) v2.7.2 (PyPI `aihf`, MIT) |

> **교육·연구 목적 전용.** 이 서비스는 실제 주문을 내지 않으며 투자 자문이 아니다. 업스트림 프로젝트의 면책 조항을 그대로 따른다.

## 1. 배경

`ai-hedge-fund`는 "AI 애널리스트로 운영되는 헤지펀드"를 시뮬레이션하는 오픈소스다. v2에서 엔진이 전면 재작성되어
**펀드(Fund) → 전략(Strategy) → 애널리스트 모델(Model)** 3계층 구조, 시점 정합(point-in-time) 백테스트,
해시 체인 원장을 가진 페이퍼 트레이딩을 제공한다. 다만 인터페이스가 **터미널(TUI/CLI)뿐**이라

- 터미널에 익숙하지 않으면 진입이 어렵고,
- 수익 곡선·애널리스트 논거(thesis)·주문 내역을 한 화면에서 훑어보기 불편하며,
- 결과를 다른 사람에게 보여 주기 어렵다.

## 2. 목표

엔진은 손대지 않고(`aihf` 패키지를 라이브러리로 의존), 그 위에 **웹 API + 웹 UI**를 얹는다.

1. 브라우저에서 맨데이트(펀드 설계)를 만들고, 백테스트하고, 페이퍼 펀드를 운용한다.
2. 모든 숫자 뒤의 근거(애널리스트별 신호·논거, 리스크 클램프, 주문·체결)를 드릴다운으로 볼 수 있다.
3. API 키가 없어도 **데모 모드**로 전체 흐름을 체험할 수 있다(합성 시세 + 규칙 기반 가짜 LLM, 화면에 항상 DEMO 표기).
4. TUI/CLI와 **같은 저장소(`~/.hedge-fund/`)를 공유**해, 터미널에서 만든 펀드가 웹에 보이고 그 반대도 성립한다.

### 비목표 (이번 범위 밖)

- 실거래(브로커 연동), 다중 사용자·로그인, 클라우드 배포
- 분 단위(minute) 펀드와 상주 러너(`aihf paper run`) — 웹에서는 daily/weekly/monthly만 지원
- 엔진 로직 수정·포크 (업스트림 업그레이드를 쉽게 유지하기 위함)

## 3. 사용자와 시나리오

| 사용자 | 하고 싶은 일 |
| --- | --- |
| 퀀트/투자 공부하는 개인 | 버핏·그레이엄 에이전트 조합이 과거에 어땠는지 백테스트로 확인 |
| 엔진 기여자 | 새 전략 YAML을 넣고 결과를 시각적으로 검증 |
| 처음 써 보는 사람 | 키 발급 없이 데모로 구조를 이해 |

핵심 시나리오

1. **설계** — 전략 라이브러리(Deep Value, Earnings Drift …)에서 고르고 자본 배분·리스크 한도·리밸런싱 주기를 정해 맨데이트 저장
2. **검증** — 종목(유니버스)과 기간을 주고 백테스트 → 벤치마크 대비 곡선, 샤프, MDD, 리밸런싱별 논거 확인
3. **운용** — 맨데이트를 페이퍼 펀드로 배치 → 다음 세션에 실행될 결정을 확인(승인)하고 한 세션씩 전진 → 원장·성적표 확인, 필요 시 킬 스위치

## 4. 핵심 기능 (MVP)

| # | 기능 | 설명 |
| --- | --- | --- |
| F1 | 대시보드 | 모드(DEMO/LIVE), 맨데이트·백테스트·페이퍼 펀드 현황 요약 |
| F2 | 맨데이트 관리 | 목록·상세·생성(빌더)·삭제. 전략 라이브러리/애널리스트 카탈로그 제공 |
| F3 | 백테스트 | 비동기 실행 + 진행률, 결과 리포트(지표·곡선·낙폭·리밸런싱·성적표), 세션 드릴다운, 이력 |
| F4 | 페이퍼 트레이딩 | 배치, 상태(NAV·포지션·대기 결정), 다음 세션 미리보기 후 실행, 다중 세션 따라잡기, 정지/재개, 세션 이력·성적표 |
| F5 | 설정 | 모드 전환, LLM 모델 선택, API 키 등록(마스킹 표시) |
| F6 | 데모 모드 | 합성 데이터·휴리스틱 LLM으로 전 기능 동작, 별도 저장소로 실데이터와 격리 |

## 5. 성공 기준

- 키 없이 설치 직후 5분 안에 "맨데이트 생성 → 백테스트 → 페이퍼 펀드 1세션 실행"이 브라우저에서 끝난다.
- 웹에서 만든 백테스트 결과 JSON은 업스트림 `FundBacktestResult` 스키마와 동일하다(상호 호환).
- 백엔드 자동 테스트와 브라우저 E2E 검증을 통과한다.

## 6. 리스크와 대응

| 리스크 | 대응 |
| --- | --- |
| 실키 없이 개발 → LIVE 경로 미검증 | LIVE는 업스트림 코드 경로(`FDClient`, `make_llm`)를 그대로 호출하도록 얇게 유지, 미검증 사실을 문서에 명시 |
| LLM 호출이 느림(수십 초~분) | 작업 큐 + 폴링 진행률, 엔진의 프롬프트/데이터 디스크 캐시 재사용 |
| 데모 결과를 실제로 오해 | 데모는 저장소 분리 + 전 화면 DEMO 배지 + 논거에 `[demo]` 접두 |
| 로컬 API가 키를 쓰는 엔드포인트 보유 | 기본 `127.0.0.1` 바인딩, 키는 마스킹만 반환, 외부 노출 금지 문서화 |
| 업스트림 API 변경 | `aihf==2.7.2` 고정, 엔진 접점을 `engine/` 한 패키지로 격리 |
