# 05. UI 설계

## 1. 정보 구조

```
[사이드바]  대시보드 / 맨데이트 / 백테스트 / 페이퍼 펀드 / 설정      [상단] DEMO·LIVE 배지

/                     대시보드
/mandates             맨데이트 목록          → /mandates/new  빌더
/backtests            백테스트 실행 + 이력   → /backtests/:id 리포트
/funds                페이퍼 펀드 목록+배치  → /funds/:name   콘솔
/settings             모드 · 모델 · API 키
```

## 2. 화면별 구성

### 대시보드
- 상태 띠: 모드, live 준비 여부(부족한 키 안내 → 설정 링크)
- 숫자 타일 3개: 맨데이트 / 백테스트 / 페이퍼 펀드
- 최근 백테스트 표(수익률·초과수익·샤프), 펀드 카드(NAV, 수익률, 정지 표시)
- 비어 있으면 "첫 맨데이트 만들기" 한 줄 안내

### 맨데이트 빌더
1. 이름
2. 전략 추가: 라이브러리 카드(Deep Value / Earnings Drift / Fundamental L/S / Inflections) 토글 + "직접 조합"(애널리스트 체크 → 모드 자동 결정)
3. 전략별 자본 비중(상대값, 합계 대비 % 미리보기)
4. 리스크: 종목당 한도, 총 노출, 절반 축소 낙폭, 전량 청산 낙폭
5. 자본, 리밸런싱 주기, 벤치마크
- 서버 검증 오류는 폼 하단에 필드 경로와 함께 표시

### 백테스트
- 실행 폼: 맨데이트 선택, 유니버스(프리셋 칩 토글 + 직접 입력), 기간
- 실행 중: 진행 막대(n/N 세션) + 실시간으로 자라는 곡선
- 이력 표: 클릭하면 리포트

### 백테스트 리포트 / 펀드 콘솔 (같은 부품 재사용)
- KPI 타일: 총수익, 벤치마크, 초과수익, 샤프, MDD, 거래비용
- **수익 곡선**: 펀드 vs 벤치마크 선 2개, 호버 크로스헤어 + 툴팁, 범례 직접 표기
- **낙폭 곡선**: 0 기준 아래로 내려가는 면적
- 포지션 표: 수량, 평가액, 비중 막대
- 세션 표: 날짜, NAV, 체결(주문 수·비용), 결정(신호 수·클램프). 행 클릭 → **세션 상세 패널**
  - 결정: 전략별 슬라이스, 애널리스트 신호 칩(강세/약세/중립/기권 + 확신도)과 논거 전문, 목표 → 최종 비중, 클램프 사유
  - 체결: 주문·체결가·수량
- 성적표: 애널리스트(적중률, IC, t-stat, 표본 수), 전략(P&L, 승률, 기여도)

### 펀드 콘솔 추가 요소
- 상단: NAV, 누적 수익률, 마지막 세션, 상태(운용 중/정지)
- **다음 세션 실행** 버튼 → 미리보기 다이얼로그(실행될 세션, 체결될 목표 비중) → 확인 시 작업 시작
- "밀린 세션 따라잡기"(최대 60)
- 정지(사유 입력) / 재개, 이벤트 로그

### 설정
- 모드 토글(live 불가 시 사유 표시), 모델 선택, 키 입력(등록된 키는 마스킹)

## 3. 시각 규칙

- 색 토큰은 CSS 변수로 정의하고 다크 모드에서 재정의. 본문 배경을 명시.
- 의미 색은 텍스트·부호와 병행: 수익은 `+`/초록, 손실은 `−`/빨강, 색만으로 구분하지 않는다.
- 차트 계열색: 펀드 = 강조색(파랑), 벤치마크 = 중립 회색. 범례는 선 끝/상단에 직접 표기.
- 숫자는 tabular-nums, 금액은 통화 기호·천 단위, 비율은 소수 1~2자리.
- DEMO일 때 상단 배지와 리포트 헤더에 "합성 데이터" 문구 고정.
- 모바일: 사이드바 → 상단 가로 탭, 표는 카드 내부 가로 스크롤.
