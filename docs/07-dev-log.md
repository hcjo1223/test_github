### M2~M3 백엔드 (`62ed84e`)
- `engine/`(aihf 접점) – `services/` – `api.py` 3층. 작업 큐는 단일 워커.
- 결정: demo 저장소를 `~/.hedge-fund/web-demo/`로 분리, live는 CLI/TUI와 공유.
- 결정: 진행률은 SSE 대신 폴링(0.7초).

### M4 프런트엔드
- React 19 + TypeScript + Vite, 라우터 외 런타임 의존성 없음. 차트는 직접 그린 SVG(선 2개 + 크로스헤어 툴팁, 낙폭 면적).
- 백테스트 리포트와 펀드 콘솔이 같은 부품(곡선·세션 표·세션 상세·성적표)을 공유 — 둘 다 같은 `SessionRecord`를 보는 화면이기 때문.
- 계열색은 검증된 팔레트의 1·2번(파랑/주황)을 라이트·다크 각각 지정하고 색각 이상 분리도 검사를 통과시켰다. 손익은 색과 함께 항상 부호를 표기.

### M5 검증에서 잡은 문제

| # | 증상 | 원인 | 조치 |
| --- | --- | --- | --- |
| 1 | 데모 P/E가 1.09 | EPS를 주가와 무관한 랜덤워크로 생성 | P/E를 랜덤워크로 두고 `EPS = 주가 / P/E`로 역산 |
| 2 | 데모 기록의 `llm_model`이 `claude-opus-5-5` | 엔진이 환경변수 `HEDGE_FUND_LLM_MODEL`을 레코드에 기록 | 엔진 실행 구간에서만 변수를 모드에 맞게 고정 |
| 3 | 첫 화면에서 `/api/funds` 등이 500 | 대시보드의 동시 요청 3개가 작업 디렉터리 생성·시드를 경합 | `Workspace.ensure()`에 락, 동시 요청 회귀 테스트 추가 (E2E가 발견) |
| 4 | `/api`가 UI의 index.html을 반환 | SPA 폴백이 `api/` 접두만 제외 | `api` 자체도 404 처리 |
| 5 | 데모 주가가 $11,979 → 한 주가 순자산의 11% | 14년 복리로 가격 수준이 폭주 | 기준일(2025-01-02)에 $20~300이 되도록 수준 고정 |
| 6 | 세션 없는 펀드에서 콘솔에 404 | 성적표를 무조건 요청 | 세션이 있을 때만 요청 |
